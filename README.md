# Single-Page CV

A simple, single-page CV built with semantic HTML and CSS, styled to follow the provided CV reference.

## Project URL

[https://github.com/zefasil20/Single-Page-CV](https://github.com/zefasil20/Single-Page-CV)

## Built With

- HTML5
- CSS3

## Run Locally

This is a static HTML and CSS project and does not require dependencies, a build step, or a development server. Keep `styles.css` and the `images` folder alongside the HTML file so the styles and favicon load correctly.

1. Clone the repository:

   ```bash
   git clone https://github.com/zefasil20/Single-Page-CV.git
   ```

2. Open the project folder.
3. Open `single-page cv.html` in a web browser.

Alternatively, open the project folder in a code editor such as Visual Studio Code and open `single-page cv.html` in your browser. A local preview extension such as Live Server is optional.

## Project Contents

- `single-page cv.html` — the CV content and page structure.
- `styles.css` — the layout, colors, and responsive styling.
- `images/favicon.ico` — the page favicon.

## Customization

Edit `single-page cv.html` to update the CV content, contact details, social profile links, page description, and Open Graph metadata. Edit `styles.css` to adjust the layout, colors, and typography. Replace any example or placeholder details with information you want to publish.
